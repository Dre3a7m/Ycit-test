# 实安课堂 · 视频弹题助手

> 一个给「盐城工学院 实验室安全育人智慧学习系统」（`sa.ycit.edu.cn`）用的油猴脚本。
> 把视频里"看到一半突然弹出来"的章节测验，改成你说了算：想什么时候弹就什么时候弹，想弹第几题就弹第几题。

当前版本：**v1.1.0**

---

## 为什么需要它

这类平台把习题挂在视频的**固定时间点**上：播放进度一旦跨过某个秒数，播放器暂停并弹出题目，答完才能继续。

正常看一遍 3 分钟的片子可能只有 1 题，但有的章节挂 3 题、5 题，而且必须**从头播到那个点**才会触发。如果前面的内容已经看过，这一段就是纯等待。

这个脚本做三件事：

1. **直接弹** —— 不播视频，按题号把题目调出来；
2. **跳到点** —— 解除"拖进度条就拉回去"的限制，把进度直接甩到题目触发的那一秒；
3. **看得快** —— 解除倍速限制，8x 播放也不会被判定为快进而回拉。

## 安装

1. 浏览器装好 **Tampermonkey（篡改猴）**；
2. 点扩展图标 → **管理面板** → 左上角 `+` **新建脚本**；
3. 删掉模板内容，粘贴 `ycit-video-quiz.user.js` 全文；
4. `Ctrl + S` 保存；
5. 打开 `sa.ycit.edu.cn`，进入任意一个带视频的章节页（`courseDetail`），**刷新**。

右下角出现「弹题助手 · 共 N 题」的面板即安装成功。

> 只对 `https://sa.ycit.edu.cn/*` 生效，不需要任何额外权限（`@grant none`），不联网、不上传任何数据。

## 面板

```
弹题助手 · 共 5 题
上排＝跳到该题触发点，下排＝直接弹出
跳转  [第1题 · 12s] [第2题 · 48s] [第3题 · 96s] [第4题 · 150s] [第5题 · 203s]
弹出  [1] [2] [3] [4] [5]
工具  [解锁快进] [8x] [列表]                                     ×
```

| 区域 | 说明 |
|---|---|
| **跳转** | 每个按钮显示「第几题 · 多少秒」。点击 = 解锁快进 + 把 `currentTime` 设到 `ejectTime + 0.5`，由播放器自己的逻辑弹出题目 |
| **弹出** | 不走视频，直接把该题的数据填进弹窗并显示 |
| **解锁快进** | 让组件"把进度拉回去"的赋值失效；只允许往前跳 |
| **8x** | 设置播放倍速（8x 时每次 `timeupdate` 前进约 2 秒，低于 3 秒阈值，不会触发回拉） |
| **列表** | 在控制台打印全部题目（序号 / 触发秒数 / 题型 / 题干） |
| **×** | 关闭面板，刷新页面会重新出现 |

面板会跟着题量自动重建：切章节、视频加载完成后，按钮数量会同步变化。

## 控制台 API

除了点按钮，也可以在 Console 里直接调用：

```js
YQ.list()          // 表格：序号 / ejectTime / 题型 / 题干
YQ.pop(0)          // 直接弹出第 1 题（索引从 0 开始）
YQ.jump(0)         // 跳到第 1 题的触发点，让它自己弹
YQ.speed(8)        // 倍速
YQ.unlockSeek()    // 只解除拖拽锁，不跳转
YQ.submit('A')     // 单选/判断：填 A 并提交
YQ.submit('AC')    // 多选：填 A、C 并提交
YQ.vm              // 拿到 Vue 组件实例，自己折腾
```

> `pop()` / `jump()` 只负责把题目弄出来，**答题仍要你自己选、自己点「提交」**，那一步才是真正调接口记成绩。

## 原理（逆向自 `chunk-1692b7a8`）

平台的视频组件在 `timeupdate` 事件里做了这些事：

```js
timeUpdate(e) {
  this.timeStamp = parseInt(e.target.currentTime)

  // 1. 快进检测：比上次记录的位置超前 3 秒以上，就拉回去
  if (e.srcElement.currentTime - this.currTime > 3) {
    e.srcElement.currentTime = this.currTime
  }

  // 2. 每 10 秒向服务端上报一次观看进度
  if (this.timeStamp % 10 === 0) { /* POST finishRate */ }

  // 3. 弹题：整数秒严格相等才弹
  this.model.questionRelaList.forEach(s => {
    if (s.ejectTime == this.timeStamp) { /* pause + showModal */ }
  })

  this.currTime = e.srcElement.currentTime
}
```

三个关键点对应脚本的三个功能：

| 平台逻辑 | 脚本对策 |
|---|---|
| `currentTime - currTime > 3` 就拉回 | 重定义元素上的 `currentTime` setter，**只接受向前赋值**，拉回操作被静默忽略 |
| `ejectTime == parseInt(currentTime)` 精确相等 | 跳转时设成 `ejectTime + 0.5`，保证 `parseInt` 结果正好命中 |
| 弹窗数据全在 `vm.model.questionRelaList` | 直接读组件数据、直接写 `vm.showModal` 等字段 |

题目内容本身做了字体混淆（页面上能看到、复制出来是乱码），但组件数据是明文，脚本读取的是后者。

## 常见问题

**面板不出现？**
- 确认当前是**视频页**（地址含 `courseDetail`，页面里有 `<video>`），课程列表页没有视频组件；
- 视频还没加载完时组件数据为空，等几秒或刷新；
- 打开控制台看有没有 `[弹题助手] 已绑定组件，弹题数 = N`。

**点「跳转」没反应 / 没弹题？**
- 说明该题的 `ejectTime` 与当前 `currentTime` 没对上，先点「列表」核对秒数；
- 有些视频的题目是后端按观看行为动态下发的，需要先播一小段让 `questionRelaList` 填充。

**倍速又被改回去了？**
- 先点一次「解锁快进」再设倍速；个别章节的播放器会监听 `ratechange` 强行重置。

**弹窗弹出来了，提交失败？**
- 那是平台接口的问题（登录态过期最常见），重新登录后再试；
- 提交成功后视频会自动 `play()`，不想让它播就先暂停。

**答完题会影响学时统计吗？**
- 会。平台每 10 秒上报一次 `watchDuration`，跳着答完，服务端记录的观看时长就是跳到的那个位置。是否被判定为"完成"取决于平台的校验策略，脚本不处理这部分。
